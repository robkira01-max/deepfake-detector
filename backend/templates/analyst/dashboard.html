Étape 1 sur 3
Bienvenue, {{ user.username }} 👋
DeepfakeDetector est une plateforme d'analyse forensique de médias numériques. Elle vous aide à évaluer l'authenticité d'une vidéo, d'un audio ou d'un document dans le cadre d'un dossier juridique.

Important : cet outil assiste l'expert humain. Il ne conclut pas à lui seul — une validation par un professionnel qualifié est toujours nécessaire.
Étape 2 sur 3
Créez votre premier dossier
Un dossier regroupe tous les fichiers d'une même affaire : vidéos, audios, documents. Il est associé à une juridiction (Canada fédéral, Québec, Ontario, Djibouti) et à un numéro de référence interne.

Chaque action sur ce dossier est inscrite dans un journal d'audit SHA-256 chaîné, immuable.

Étape 3 sur 3
Déposez une pièce pour analyse
Depuis un dossier, déposez un fichier (vidéo, audio, image, PDF). La plateforme calcule automatiquement les empreintes SHA-256 + Blake3 et obtient un horodatage TSA RFC 3161 pour certifier l'antériorité.

Le fichier est ensuite analysé par les moteurs forensiques disponibles.
